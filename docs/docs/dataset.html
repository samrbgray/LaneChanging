Structure

What's Included

Positional Dataset


High-frequency RTK-GPS trajectory files (XLSX) for each trial. Includes pre-processed lane distances, vehicle role labels, and a common longitudinal reference. Available for both ACC and FSD driving modes.


ACC FSD 20 Hz

Video Dataset


Forward-facing camera footage from the LCV for each trial. Recorded at 1920×1080, 30 fps, 84° FOV. Synchronized with GPS timestamps.


MP4 30 fps 1080p

Energy Dataset


CAN bus energy consumption data logged via ScanMyTesla for each trial. Enables analysis of how lane-change aggressiveness affects EV energy use.


CAN Bus Tesla

Column Definitions

ColumnUnitsDescription
GPS_TOWsecondsGPS Time of Week — absolute time reference for cross-vehicle synchronization
Raw_TimestampsecondsElapsed time from trial start (t = 0 at first record)
DateTime_EST—Wall-clock datetime in Eastern Standard Time
Latitudedecimal degreesWGS-84 latitude (RTK-corrected, ±0.01 m)
Longitudedecimal degreesWGS-84 longitude (RTK-corrected, ±0.01 m)
AltitudemetersEllipsoidal altitude above WGS-84 reference
HeadingdegreesVehicle heading from North (0–360°)
Speed_mpsm/sGround speed from INS/RTK fusion
LeftLane_Lat / _Londecimal degreesProjected left lane boundary coordinate at this timestep
RightLane_Lat / _Londecimal degreesProjected right lane boundary coordinate at this timestep
LongDist_LeftLane_mmetersLongitudinal distance traveled along the left lane centerline from trial start
LatDist_LeftLane_mmetersLateral offset from left lane marking (+ toward left, – away)
LatDist_RightLane_mmetersLateral offset from right lane marking
LaneSpacing_mmetersEstimated lane width at this position
VehicleType—Role label: LV, LCV, F1, or F2
Rel_Longitudinal_Dist_from_LCmetersSigned distance from the lane-change event (– = before, + = after)
LongDist_LeftLane_m (Common Reference)metersLongitudinal position in a shared reference frame across all vehicles in the trial
