Trajectory Animations

Code/animations/

View on GitHub →

Generates bird's-eye-view trajectory animations from the processed positional XLSX files. Each frame renders vehicle positions, lane markings, and relative distances for all four vehicles simultaneously, producing an MP4 or GIF of the full lane-change event.

Usage


# Install dependencies
pip install pandas openpyxl matplotlib ffmpeg-python

# Run animation for a single trial
python animate_trial.py --input Data/Sample/FSD/LC/S78_DS2_DV0.xlsx --output Output/LC/Video/

# Batch process all trials in a folder
python animate_batch.py --input_dir Data/Sample/FSD/LC/ --output_dir Output/LC/Video/

Input: any NC-tALC positional XLSX file. Output: MP4 animation saved to the specified output directory.

Measure Plots

Code/measure_plots/

View on GitHub →

Produces standard analysis figures from the positional data — including speed profiles, lateral distance time series, longitudinal gap evolution, and surrogate safety measure plots. Designed to work directly with the NC-tALC XLSX schema.

Usage


# Install dependencies
pip install pandas openpyxl matplotlib seaborn scipy

# Generate all plots for a trial
python plot_measures.py --input Data/Sample/FSD/LC/S78_DS2_DV0.xlsx

# Compare FSD vs ACC across multiple trials
python compare_modes.py --fsd_dir Data/Sample/FSD/LC/ --acc_dir Data/Sample/ACC/LC/

Outputs PNG figures to a local figures/ directory by default. Pass --output_dir to specify a custom path.
